# Security

Report security bugs by email to security@lumbridgecorp.com. Do not open a public issue with exploit details.

Include your `lbc --version`, OS, whether the problem is local or remote, steps to reproduce, and the impact you expect. Remove secrets from logs and examples. A small reproduction helps.

The latest release and the latest `main` are supported. We answer in the same email thread. There is no fixed response deadline.

See [Security and trust](docs/security.md) for the runtime's access and trust model.
